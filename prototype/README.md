# Muse Local · 原型 v0.6

纯静态原型，不需要安装任何工具，也不需要构建。

## 怎么打开

双击 `index.html`，或者把它拖进浏览器窗口。

四个文件必须放在同一个目录里：`index.html`、`styles.css`、`data.js`、`app.js`。

## 这一版的设定

- **对话在左边，电脑画面在右边，但默认不显示**。画面只在你要看的时候展开：点对话里的任意一张快照，右边的实时画面就打开了。
- **电脑没有图形桌面**，所以右边只会显示 AI 正在操作的那**一个应用窗口**，没有窗口时那块面板根本不出现。
- **面板可以折叠、可以拖动调宽、可以放大**：面板右上角有 `⌄` 折叠、`⤢` 放大；中间的分隔线按住拖能改宽度，双击复位。
- **接管后可以直接操作那个浏览器**：点击、打字、滚动都真实生效。
- **对话区参考 Codex 的排版**：助手消息是纯文本没有气泡，用户消息是右对齐的浅色块，工具调用是一行「圆点 + 名字 + 参数 + 状态」，点开才看细节；命令输出是深色终端块。
- **完成卡片默认只有一行**，耗时 / Token / 费用折叠在「详情」里。
- 只有一台电脑 `ubuntu-01`，软件启动时自动创建，所有对话共用。白色主题，线分割。

## 建议的浏览顺序

1. 打开时右边是空的——因为这台电脑当前没有打开任何窗口。对话里有一段历史：用户让它打开 Google 首页。
2. **点对话里那张 Google 快照**，右边的面板展开，里面是那个浏览器窗口，可以直接接管操作。
3. 点 **接管窗口**（画面右上角）。边框变紫、左上角出现「你在控制」，鼠标进画面后变成画面里的指针。现在可以：
   - 点搜索框 → 出现闪烁光标，直接打字（Backspace 删除，Esc 退出），回车或点「Google 搜索」跳到结果页；
   - 点任意一条结果 → 打开文章页，可以滚轮上下滚；
   - 点 ‹ › 后退前进，⟳ 重新加载，点标签页的 ✕ 关掉窗口，点 ＋ 重新打开；
   - 没接管的时候点画面只会提示你先接管。
4. 点 **⤢ 放大** 可以把画面弹到全屏大小的窗口里操作，底部同样有接管 / 交还按钮。
5. 点 **⌄ 折叠** 收起画面，回到纯对话。
6. 点底部第一个示例 **「打开浏览器访问 Google 首页」**，会走一遍完整流程：AI 回复 → 浏览器窗口出现 → 快照 → 可以点快照进入。第二个示例是完整的 Hacker News 任务，中途有两张**审批卡片**（装 Python 包、写宿主桌面），拒绝第二张能看到 AI 改方案。
7. 完成后那张卡片只显示一行，点右边的 **详情 ⌄** 才展开耗时和费用。
8. 左侧 **任务** 页、**设置** 页照旧；左下角 **环境** 里有「环境自检 / 已装软件 / 已连接服务」三个页签。

## 原型里是假的

- 没有真实的虚拟机、QEMU 或模型调用，窗口和回复都是预先编排的；假浏览器是用 DOM 画的，不是真截图。
- 浏览器只在「接管」状态下响应点击，且只能走上面列出的那几条路径。
- 软件清单和连接服务来自你贴的那段 Muse 对话，是静态数据。
- 刷新页面就回到初始状态（画面重新变成折叠）。

## 和开发文档的对应

`../docs/DEVELOPMENT.md` 是按「有完整桌面、多台电脑」写的。这一版原型改成**无桌面、单机、按窗口转播、按需展开**之后，文档里这几处需要跟着改：

- Guest 镜像不再需要 XFCE 桌面、xdotool、桌面截图工具，只需要浏览器 + 无头虚拟显示（Xvfb 或 Wayland headless）；
- 画面通道从「整屏 VNC」改成「按窗口取画面」，需要窗口枚举与单窗口抓取；前端要能把画面坐标映射回逻辑坐标（原型里的点击映射就是这个思路）；
- 画面改成**按需订阅**：没有观看者时不推流，这也顺带省掉了持续编码的开销；
- 接管要区分「看画面」和「发输入」两件事，输入通道需要单独设计；
- `ComputerProvider` 的多实例、端口池、多机并发可以简化成单实例；
- 可以补上原型里已经画出但文档没写的两块：**电脑信息（已装软件 / 已连接服务）** 和 **终端输出文本流**。
