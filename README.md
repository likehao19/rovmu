# rovmu

一个「让 AI 拥有一台本地电脑」的桌面软件原型与开发文档。

思路是在用户自己的机器上用 QEMU 起一台 **没有图形桌面** 的 Linux 电脑，交给 AI 自主操作 —— 开浏览器、跑命令、写文件 —— 用户按需观看那个应用窗口的实时画面，并随时接管自己操作。

## 目录

| 路径 | 内容 |
|---|---|
| `docs/DEVELOPMENT.md` | 开发文档：架构分层、模块设计、接口契约、数据模型、状态机、镜像构建、安全模型、里程碑与测试策略 |
| `prototype/` | 纯静态交互原型，用来对齐交互 |

## 原型

不需要安装任何工具，也不需要构建，双击 `prototype/index.html` 就能打开。

建议先看这几件事：

1. 点对话里的**快照**，右侧展开那个浏览器窗口的实时画面；
2. 点 **接管窗口**，直接在里面点击、打字、搜索、打开文章、前进后退、滚动；
3. 点 **⤢ 放大** 把画面弹到大窗口操作，点 **⌄ 折叠** 收起来；
4. 跑一遍底部第一个示例，看 AI 从打开浏览器到生成表格的完整过程，中途会有两张**审批卡片**。

细节和已知的「假」的部分都写在 `prototype/README.md` 里。

## 现状

只有文档和原型，没有后端实现。原型里的虚拟机、浏览器画面、模型回复全部是本地模拟的，用 DOM 画出来，不涉及真实的 QEMU 或模型调用。
